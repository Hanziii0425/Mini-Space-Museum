# Mini Space Museum 

An interactive Augmented Reality (AR) Mini Space Museum built using **A-Frame** and **AR.js**.

## Project Description

This project creates a small interactive space museum using a Hiro AR marker. When the marker is detected through the camera, users can explore a 3D solar system with planets, stars, a rocket, and other space objects.

## Technologies Used

- HTML
- A-Frame
- AR.js
- JavaScript
- 3D GLB models

## Features

- Hiro marker-based Augmented Reality.
- Interactive 3D space objects.
- Animated planets and space objects.
- Clickable objects with colour-changing and scaling interactions.
- Marker detection status banner.
- 3D astronaut model.

## How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Run `index.html` using Live Server.
4. Allow camera access.
5. Show the Hiro marker to the camera.
